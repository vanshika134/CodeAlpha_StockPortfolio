# PortfolioPilot – Stock Portfolio Tracker

PortfolioPilot is a web-based stock portfolio management application built using Python Flask and SQLite. It allows users to manage stock holdings, track transactions, and monitor portfolio performance.

## Features
- Buy and sell stocks
- Track current stock holdings
- Calculate total investment and profit/loss
- View transaction history
- Export portfolio data to CSV
- Store portfolio data using SQLite
- Responsive dashboard with portfolio allocation chart

## Technologies Used
- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
- Chart.js

## Demo Stock Prices
The application uses fixed sample stock prices for demonstration. It does not use live market data.

## How to Run
1. Clone or download the repository.
2. Install dependencies:
   `pip install -r requirements.txt`
3. Run the application:
   `python app.py`
4. Open `http://127.0.0.1:5000` in your browser.

## Project Purpose
To demonstrate practical web development, database management, CRUD operations, and portfolio tracking through a simple interactive application.
